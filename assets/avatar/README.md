# Character Avatar Assets

Place the six bundled/default character avatar images in this folder.

Supported formats:
- PNG
- JPG / JPEG
- WEBP

The Roster > Characters profile card discovers these files dynamically. Clicking the circular character portrait opens the avatar picker.

Bundled defaults are persisted as repo-relative paths such as:
`assets/avatar/avatar_name.png`

Custom user-selected portraits are copied to:
`data/avatar/`

Custom portraits are user-owned runtime data and are not part of the application asset bundle.
