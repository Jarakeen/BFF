# Vision

Black Feather Foundry is an operations center for Elder Scrolls Online.

Its purpose is to help players and guilds plan expeditions, manage live operations, preserve knowledge, and measure long-term progression.

The Foundry is organized around six pillars.

---

# Pillar I — Operations

The live command center.

Purpose:
Support the current expedition.

Modules

• Operations Desk
• Current Run
• Broadcast Tools
• OBS Integration
• Timers
• Alerts
• Expedition Startup
• Quick Actions

Primary Users

Raid Leader
Officers
Streamer

# Guiding Principles

Every feature should answer:

Why does this exist?

Who benefits from it?

Does it improve an expedition?

Does it preserve knowledge?

Can it be understood six months from now?

Would Granny approve of how simple it is?

---

# Long-Term Goal

Black Feather Foundry should become the operational headquarters for an ESO guild.

One application.

One workflow.

One archive.

Every run tells a story.
