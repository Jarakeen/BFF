# Finch / FoundryDock Privacy Policy

**Effective date:** September 20, 2026

This Privacy Policy explains how Finch, the Discord companion for FoundryDock, handles information.

## 1. Overview

Finch is designed to use as little Discord user data as practical.

FoundryDock remains the source of truth for raid plans, schedules, builds, assignments, strategy notes, and raid maps. Finch reads and presents that information in Discord.

Finch does not require players to create separate Finch accounts or complete an OAuth registration flow.

## 2. Information Finch May Use

Depending on how a server owner configures FoundryDock and Finch, Finch may process:

- Discord server (guild) identifiers;
- Discord channel identifiers;
- Discord role identifiers used for raid notifications;
- Discord display names or usernames when voluntarily saved in FoundryDock Personnel for player matching;
- FoundryDock team schedules;
- FoundryDock raid plans;
- FoundryDock player build and assignment information;
- encounter strategy notes;
- raid map files;
- command inputs submitted to Finch.

## 3. Information Finch Does Not Intentionally Collect

Finch is not designed to collect:

- passwords;
- Discord account credentials;
- payment-card information;
- private direct-message history;
- general message content from Discord channels;
- precise location data;
- advertising profiles.

Finch does not currently request Discord's privileged Message Content, Presence, or Server Members gateway intents for its normal operation.

## 4. Bot Token Handling

The Discord bot token used to authenticate Finch is treated as a secret credential.

On supported local installations, FoundryDock stores the token in the operating system's credential vault rather than in the FoundryDock database or ordinary configuration files.

Users should never share the bot token publicly.

## 5. Storage

FoundryDock data is generally stored locally by the person operating the FoundryDock installation.

Finch may store limited local metadata needed for operation, such as configuration identifiers and fingerprints used to detect build changes. These fingerprints are not intended to create a second copy of a player's full build or raid plan.

Discord itself may retain interactions and messages according to Discord's own policies.

## 6. How Information Is Used

Information is used only to provide Finch functionality, including:

- responding to slash commands;
- showing saved raid plans;
- showing player build and assignment briefs;
- showing team schedules;
- posting reviewed encounter strategy information;
- posting raid maps;
- sending configured raid reminders;
- sending configured build-change notices;
- maintaining and improving FoundryDock companion functionality.

## 7. Sharing

Finch does not sell personal information.

Information is shared only as needed to provide requested functionality, principally with Discord when Finch sends messages, files, command responses, or notifications through the Discord platform.

Server owners should configure channel permissions appropriately before allowing Finch to post team information.

## 8. Data Retention

FoundryDock data remains under the control of the local FoundryDock operator.

Operational metadata is retained only as long as reasonably needed for Finch features or until the operator removes the relevant local data or configuration.

Messages already sent to Discord may remain there according to server settings and Discord's own retention practices.

## 9. Data Deletion

Because FoundryDock is primarily locally operated, the local operator can remove FoundryDock data, Discord mappings, reminder configuration, and Finch operational state from their own installation.

Server owners may also remove Finch from a Discord server through Discord's normal app-management controls.

## 10. Children's Privacy

Finch is not designed to knowingly collect personal information from children. Use of Discord remains subject to Discord's age requirements and policies.

## 11. Security

Reasonable measures are used to limit credential exposure and unnecessary data collection. No software or online service can guarantee absolute security.

## 12. Third-Party Services

Finch relies on Discord for bot connectivity and message delivery. Discord's collection and use of information is governed by Discord's own privacy policy.
