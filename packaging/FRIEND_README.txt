BLACK FEATHER FOUNDRY - FRIEND TEST BUILD

1. Extract the entire ZIP to a normal writable folder such as Desktop or Documents.
2. Keep BFF.exe and the data folder together.
3. Run BFF.exe.
4. Windows SmartScreen may warn about an unsigned app. This test build is not code-signed.
5. Do not move only BFF.exe out of the folder; the app needs data\eso.db beside it.

This package starts with an empty Builds roster. Your builds are saved locally in data\builds.json inside the extracted folder.

If the app does not start, send the developer:
- what Windows displayed,
- whether BFF.exe opened at all,
- and a screenshot of the extracted folder showing BFF.exe and data\eso.db.
