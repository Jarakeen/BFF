# Icon Attribution

Black Feather Foundry uses SVG icons sourced from [Game-icons.net](https://game-icons.net/) and recolored to match the Foundry UI palette.

Game-icons.net states that its icons are generally provided under **Creative Commons Attribution 3.0 (CC BY 3.0)**, with some individual icons released as **CC0 / Public Domain**. Attribution should name the original icon author. See the source site's About / FAQ and each icon's source page for the exact author and license.

## Project attribution format

For every Game-icons.net SVG included in `assets/icon/` or `assets/icons/`, record:

| Local filename | Game-icons.net icon name | Original author | License | Source page | Modified? |
| --- | --- | --- | --- | --- | --- |
| `example.svg` | Example | Author | CC BY 3.0 | `https://game-icons.net/...` | Recolored to Foundry gold |
